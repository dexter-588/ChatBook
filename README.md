# ChatBook

Sign-up uses Supabase Auth for passwords and records user details in the `public.users` table on the user's first authenticated dashboard visit. The app matches a profile by `email`.

## Required Supabase setup

Do **not** store plain-text passwords in `public.users`; Supabase Auth handles them securely. In the SQL editor, make `email` unique and enable policies so a signed-in user can access only their own row:

```sql
alter table public.users add constraint users_email_key unique (email);
alter table public.users enable row level security;

create policy "users can read their own profile"
on public.users for select to authenticated
using (email = (select auth.jwt() ->> 'email'));

create policy "users can create their own profile"
on public.users for insert to authenticated
with check (
  email = (select auth.jwt() ->> 'email')
  and role = 'user'
);
```

Ensure `user_id` is generated by the database (identity or bigint default). The registration form supplies all other profile fields.

## Roles and admin access

Run this after the setup above. It creates the only valid roles (`admin`, `user`) and permits admins to list users and change their roles.

```sql
create table if not exists public.roles (
  name varchar(20) primary key,
  created_at timestamptz not null default now(),
  constraint roles_name_check check (name in ('admin', 'user'))
);

insert into public.roles (name) values ('admin'), ('user')
on conflict (name) do nothing;

update public.users set role = 'user' where role is null or role not in ('admin', 'user');
alter table public.users alter column role set default 'user';
alter table public.users alter column role set not null;

do $$ begin
  alter table public.users add constraint users_role_fkey foreign key (role) references public.roles(name);
exception when duplicate_object then null;
end $$;

create or replace function public.is_admin()
returns boolean language sql stable security definer set search_path = public as $$
  select exists (
    select 1 from public.users
    where email = (select auth.jwt() ->> 'email') and role = 'admin'
  );
$$;

grant execute on function public.is_admin() to authenticated;

create policy "admins can read all profiles"
on public.users for select to authenticated
using ((select public.is_admin()));

create policy "admins can update roles"
on public.users for update to authenticated
using ((select public.is_admin()))
with check ((select public.is_admin()));
```

To choose the first administrator, run this once with that account's real email:

```sql
update public.users set role = 'admin' where email = 'your-admin@example.com';
```
